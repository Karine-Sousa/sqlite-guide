# Introdução ao SQLite

## O que é SQLite?

SQLite é um sistema gerenciador de banco de dados relacional leve, gratuito e de código aberto.

Diferente de outros bancos de dados, ele não necessita de um servidor dedicado, armazenando todas as informações em um único arquivo.

## Principais Características

- Gratuito
- Portátil
- Fácil instalação
- Baixo consumo de recursos
- Amplamente utilizado

## Onde é Utilizado?

- Aplicativos Mobile
- Sistemas Desktop
- Sistemas Embarcados
- Projetos Acadêmicos
- Protótipos
